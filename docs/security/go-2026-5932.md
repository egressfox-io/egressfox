## Remediation and controls

Keep the raw finding visible in Grype JSON reports; do not ignore all Unknown
findings or the entire x/crypto module. Preserve the High/Critical failure gate,
source reachability scans and checksum-pinned builds. No vulnerable-code mitigation
is needed for the scoped artifacts because the affected packages are absent.

Re-review this record before expiry and whenever build inputs change. If OpenPGP
is introduced, this conclusion is invalid: remove the unmaintained package or use
a maintained implementation, then repeat source and artifact scans. Never carry
this record forward to a new digest without fresh evidence.
