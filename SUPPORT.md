# Support

EgressFox is a pre-release open-source project maintained on a best-effort basis.
There is no guaranteed response time, production support contract, or compatibility
commitment beyond the documented alpha support matrix.

## Where to ask

- **Reproducible non-sensitive bug:** use the repository bug-report issue form.
- **Feature or design proposal:** use the feature-request issue form and describe
  the operational problem before proposing implementation details.
- **Usage question:** search existing issues and documentation first; if the answer
  remains unclear, use the focused question form with sanitized context.
- **Potential vulnerability or sensitive disclosure:** follow
  [SECURITY.md](SECURITY.md). Never post credentials, subscriptions, Secret contents,
  generated configurations, or exploit details publicly.

The current Kubernetes model is namespace-scoped and supports explicit single-replica
managed Gateways and bring-your-own runtimes. Requests for additional protocols,
HA, cross-namespace access, or richer routing are roadmap proposals rather than
support incidents.
