# Maintainers

The current project maintainer is Ruslan ([`@flerris`](https://github.com/flerris)).

Project maintainers are responsible for:

- Project direction and architecture.
- Reviewing contributions and managing releases.
- Compatibility and versioning decisions.
- Security coordination.
- Maintaining project documentation and contributor guidelines.

## Becoming a maintainer

Contributors who consistently provide high-quality contributions, participate in
reviews, and demonstrate a strong understanding of the project may be invited by the
current maintainer to join the maintainer team.

Repository access and responsibilities are agreed explicitly when a maintainer is
invited. No additional maintainers are currently listed.

## Security

Please do not report security vulnerabilities through public issues.

Refer to [SECURITY.md](SECURITY.md) for the vulnerability reporting
process.
